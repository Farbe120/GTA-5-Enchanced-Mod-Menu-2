# GTA V Enhanced Mod Menu (C++ Source)

A complete C++ Mod Menu for **Grand Theft Auto V Enhanced Edition** featuring the **Soul Switcher Gun** and a **GTA Online Vehicles Spawner**.

## Features

* 🌀 **Soul Switcher Gun**: Shoot or target any NPC to switch body and soul into that character instantly.
* 🏎️ **GTA Online Vehicles Spawner**: Access and spawn all vehicles added in GTA Online updates (Bottom Dollar Bounties, Chop Shop, Mercenaries, Contract, Cayo Perico, etc.) directly in Story Mode.
* 🛡️ **Player Options**: Toggle God Mode, Super Jump, and Infinite Stamina.
* ⚡ **Performance**: Native C++ ASI plugin compiled specifically for `GTA5_Enhanced.exe`.

## How to Build

1. Open Visual Studio 2022.
2. Create a C++ Dynamic Link Library (`.dll`) project.
3. Paste `main.cpp` into your source files.
4. Build solution as `x64 Release`.
5. Rename output `.dll` to `.asi` (e.g., `GTA_V_Enhanced_Mod_Menu.asi`).

## Controls

* **F5**: Toggle Main Mod Menu / God Mode
* **F6**: Quick Spawn GTA Online Vehicle (e.g. *Pipistrello*)
* **Aim + Shoot at NPC**: Trigger Soul Switcher
